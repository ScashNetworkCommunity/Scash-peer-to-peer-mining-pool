HOW TO START MINING IN 3 EASY STEPS (WINDOWS):

1. KEEP THIS FOLDER ALLOWED IN WINDOWS SECURITY:
   Make sure this folder (for example C:\Scash-P2Pool) is added under:
   Windows Security -> Virus & threat protection -> Manage settings ->
   Exclusions -> Add an exclusion -> Folder.
   (This keeps Windows from deleting the built-in CPU miner and the
   WinRing0x64.sys CPU speed-booster file!)

2. DOUBLE-CLICK Start-Scash-P2Pool.exe:
   - If Windows shows 'Windows protected your PC', click More info -> Run anyway.
   - Click YES on the Administrator prompt! This turns on the MSR + HugePages
     CPU speed boost so your processor mines 2x to 4x faster.
   - If Windows Firewall asks, click Allow access.

3. PASTE YOUR scash1... WALLET ADDRESS IN YOUR BROWSER:
   - Your web browser opens http://127.0.0.1:8345/static/ automatically.
   - Paste a scash1... receiving address from your Scash Wallet and click
     'Start Built-in XMRig'!
   - SPEED TIP: Restart your PC once after your very first Administrator run
     so Windows finishes unlocking HugePages memory for maximum CPU speed!
