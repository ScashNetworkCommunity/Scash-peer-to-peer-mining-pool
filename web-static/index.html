112-Byte Scash RandomX Header Verifier

RandomX v1.2.1

Unlike Bitcoin's 80-byte SHA-256d header, Scash uses a 112-byte header (uint32_t blockHeader[28]) where bytes 80..111 hold rx_hash (zeroed during hashing) and PoW is validated via randomx_calculate_commitment.

Words 0..19 (80B Base Header): ver + prev + merkle + time + bits + nonce
Words 20..27 (32B rx_hash): 7f4e9a1b3c8d2051...8821c04f
Commitment (rx_cm < Target): 000000019b4d82e1...4a19f002
Nonce (Word 19 LE): 0x48a91f0c (1,219,043,084)
